# How Old Am I??

Website that charges **1 ETH** to calculate your age. Donations through the hole start at **0.5 ETH**.

## Before anyone pays

Open `config.js` and put your Ethereum address in `recipientAddress`.

Until that is a real `0x` address, the pay button will refuse to send funds.

## Open the site

Open `index.html` in a browser with an Ethereum wallet (MetaMask etc.).

Age checkout is **1 ETH** on Ethereum mainnet. Donations are an amount you choose, minimum **0.5 ETH**.
